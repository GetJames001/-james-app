James Privacy Policy

Internal review draft — not effective or published. This page is a design prototype. Its disclosures require factual verification before publication.

About James

James is a personal assistant being developed to help an authorized user organize schedules, messages, tasks and daily activities. The available integrations may change.

Google Calendar

The current integration requests read-only Google Calendar access to retrieve calendar information for display and scheduling awareness. James uses a server-side OAuth refresh token to request access tokens. The current integration does not request Calendar write permission.

Email, tasks and AI processing

James can retrieve Microsoft email information, including message subjects, senders, previews and message bodies, and maintain task and attention records. Selected email information may be transmitted to OpenAI for AI-assisted triage. The application requests Microsoft Mail.Read and Mail.Send permissions; its available actions depend on the current implementation and authorization. This draft does not establish a complete inventory of providers or data disclosures.

Security

The current application uses authenticated sessions and server-side token handling. No service can guarantee absolute security.

Retention, deletion and user choices

James stores connection credentials and some task and attention information server-side. Retention periods and deletion procedures are being verified. You can revoke Google authorization through your Google Account. For requests to review or delete James-held information, contact privacy@getjames.ai; procedures and applicable limitations must be verified before this draft is published as an effective policy.

Contact

For privacy questions, email privacy@getjames.ai.

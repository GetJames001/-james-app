# Saved Hotmail review bridge — November 5, 2026

Uses the existing Attention evaluator, snapshot store and Microsoft personal-mail connection. It does not install another scheduled monitor or touch credentials. The existing snapshot GET remains read-only; the separate authenticated same-origin POST /api/attention/scan collects the latest returned personal Inbox page, up to 25 messages, and saves bounded review evidence.

Every returned message is inventoried before the conservative signal filter. Unknown messages remain in saved evidence. Signals include mailbox flags/importance, explicit response requests, possible bills/career responses and possible itinerary/booking notices. These are review candidates, not verified obligations, confirmed reservations or completed semantic classification. Collector events explicitly have uncertain extraction and unknown automation status, so the existing evaluator does not silently turn them into tasks or reminders or claim no actions exist.

Rechecks preserve previous message versions, other source state, existing policy and saved obligations; read/deleted state does not resolve anything. Collector envelopes compact while evidence remains. Failed reads retain candidates and save source failure state when storage remains available. Optimistic concurrency rejects conflicting writes. A 300-version evidence cap / existing 1 MiB snapshot cap refuses further growth without pruning saved items. No mailbox-wide checkpoint is advanced.

The UI restores saved candidates in another browser session. Check recent mail performs the explicit foreground collection/save; initial mount only reads saved state. Clicking Review in Mail retrieves a source message by ID if it is no longer in the current loaded page. Fetching that source is read-only; the existing reader marks read only after the explicit user open. Missing source messages retain their saved review item. Draft a task still requires Add task to persist a task.

Validated: 89 focused checks passed, covering existing Attention reads, storage bounds, new collection and failure retention, account/CSRF gates, source message reads, actual-browser saved-review recovery, late logout suppression, mail behavior, login bootstrap, conversation, voice and Workbench navigation. No real mailbox mutations or test messages were used by these checks. Live preview verification follows deployment.

Still absent: direct Gmail mail access; complete Inbox/folder/date paging and stable cross-folder/RFC identity reconciliation; semantic full-message/attachment extraction and matching Sent-resolution evidence; scheduled monitoring/watchdog/delivery; trip records and reviewed Calendar writes. Existing Job Assistant/Dot automations are unchanged. Do not present this increment as the complete itinerary-import system. Preserve the accepted Calendar/voice/entrance and continue those remaining layers using the recovered monitor reference.
